# Student Linked List in C

A C program that stores student records and modify it in a singly linked list.


Each student record contains a name, age, average, and a pointer to the next student.

## Features

- Create a student record
- Display all students
- Count students
- Search for a student by name
- Add a student at the beginning, a chosen position, or at the end
- Delete a student from the beginning, a chosen position, or at the end
